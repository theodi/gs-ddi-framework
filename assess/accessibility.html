Accessibility statement

This accessibility statement applies only to the DDI & AI self-assessment prototype. It does not apply to the HTML framework or data downloads, which have a separate statement.

This website is run by the Open Data Institute. We want as many people as possible to be able to use this website.

How accessible this website is

This is a JavaScript prototype, not a live government service. It is not fully compliant with WCAG 2.2 AA.

We tested it on 13 August 2026 using automated checks (axe-core 4.13.0) and a structured manual review. Automated checks found no WCAG 2.2 A or AA violations after fixes. The prototype still fails some criteria that automated tools do not score, and it cannot be used without JavaScript.

We are designing to the GOV.UK Design System so the tool can meet WCAG 2.2 AA if it becomes a live service.

Non-accessible content

  • You cannot start or continue an assessment without JavaScript. Without JavaScript you can still read this page and the HTML framework.
  • We have not completed testing with screen readers (for example NVDA, VoiceOver or JAWS), Windows High Contrast, or a 200% zoom sign-off with assistive technology users.
  • A sticky action bar on the profile steps may hide a focused field in some keyboard paths.

The audit findings, including issues we have already fixed, are published as JSON and CSV.

Feedback and contact information

If you need information in a different format, or you have found an accessibility problem, email training@theodi.org.

Technical information about this website's accessibility

The Open Data Institute is committed to making this website accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

This prototype is not fully compliant with the Web Content Accessibility Guidelines version 2.2 AA standard.

Preparation of this accessibility statement

This statement was prepared on 13 August 2026 for the prototype. It will be updated after assistive-technology testing and before any live service.
