Accessibility statement

This accessibility statement applies to the DDI & AI skills and capabilities framework HTML publication and data downloads on this website. It does not apply to the self-assessment prototype, which has its own statement.

This website is run by the Open Data Institute. We want as many people as possible to be able to use this website.

How accessible this website is

This part of the website is compliant with the Web Content Accessibility Guidelines (WCAG) 2.2 AA standard.

Pages are written as HTML following the GOV.UK Design System. You can read the framework without JavaScript. Data is also available as JSON and CSV.

Feedback and contact information

If you need information on this website in a different format, or you have found an accessibility problem, email training@theodi.org.

Technical information about this website's accessibility

The Open Data Institute is committed to making this website accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

This part of the website is compliant with the Web Content Accessibility Guidelines version 2.2 AA standard.

Preparation of this accessibility statement

This statement was prepared on 13 August 2026.

The HTML guides and data downloads were tested against WCAG 2.2 AA using automated checks (axe-core 4.13.0) and a structured manual review. Automated checks found no WCAG 2.2 A or AA violations. The full results are published as JSON and CSV.

The test did not include a separate assistive-technology user research session (for example NVDA, VoiceOver or JAWS). We will update this statement if further testing finds problems.
